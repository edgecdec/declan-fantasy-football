## TASK-004: Ensure 50% reference line is always visible on luck trends chart (2026-03-28)
- **Status**: Done
- **Changes**: Changed YAxis `domain` from `['auto', 'auto']` to use domain functions: `[(dataMin) => Math.min(dataMin, 48), (dataMax) => Math.max(dataMax, 52)]`. This ensures the 50% reference line is always within the visible chart area with a 2% buffer, while still auto-scaling to the actual data range.
- **Lessons**: Recharts `domain={['auto', 'auto']}` clips to the data range, hiding ReferenceLine elements outside that range. Domain functions allow dynamic min/max that guarantee specific values are included. The fix was a single line change — minimal and focused.
