- Fix: Added slot_to_roster_id to SleeperDraft type. Built a slotToRosterId map in DraftBoard and passed it to DraftGrid. Column headers now use getRosterId(draftSlot) to look up the correct roster_id for display names. Traded pick ownership lookups also use the correct roster_id.
- Key lesson: The league drafts endpoint (GET /league/{id}/drafts) returns slot_to_roster_id as null. Only the individual draft endpoint (GET /draft/{id}) returns it. Had to add a getDraft() call after selecting the best draft.
- Lesson: draft_slot is the position in the draft order (1st pick, 2nd pick, etc.), NOT the roster_id. Always use slot_to_roster_id to convert between them.
