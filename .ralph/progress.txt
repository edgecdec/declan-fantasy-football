## TASK-001: Filter out zero-point leagues from expected wins (2026-03-28)
- Fix: In `analyzeLeague()`, return `userStats` as `undefined` when `pointsFor === 0`, so zero-point leagues (test leagues, leagues with no real games) are excluded from all downstream aggregation.
- Change was 1 line: check `myStats.pointsFor > 0` before returning userStats.

- Lessons: Nova Act browser tests with long-loading pages (multiple Sleeper API calls) need generous wait times or polling. The `time.sleep(45)` wasn't enough for the trends page which fetches ~8 years of data. Consider using Playwright's `waitForSelector` on chart elements instead of fixed sleeps.

## TASK-004: Ensure 50% reference line is always visible on luck trends chart (2026-03-28)
- **Status**: Done
- **Changes**: Changed YAxis `domain` from `['auto', 'auto']` to use domain functions: `[(dataMin) => Math.min(dataMin, 48), (dataMax) => Math.max(dataMax, 52)]`. This ensures the 50% reference line is always within the visible chart area with a 2% buffer, while still auto-scaling to the actual data range.
- **Lessons**: Recharts `domain={['auto', 'auto']}` clips to the data range, hiding ReferenceLine elements outside that range. Domain functions allow dynamic min/max that guarantee specific values are included. The fix was a single line change — minimal and focused.
